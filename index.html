This dashboard delivers a complete overview of workforce performance by department, highlighting hiring trends over time, gender diversity, active employee counts, years since last promotion, and salary distribution across job roles.

The Map Project

Developing a custom Egypt GeoJSON map from scratch, creating a workaround for Power BI's lack of offline Egypt map support and enabling interactive geographic visualizations without internet access or external map services.

2 SCREENS
The Map

Engineered a custom Egypt GeoJSON map as a technical workaround to enable interactive geographic reporting in Power BI within a restricted offline environment. Designed and built the map from scratch by defining governorate polygons, coordinate geometry in JSON/GeoJSON, then consolidated all governorates into 11 regions preserving accuracy. Optimized and simplified the geometry using Mapshaper and other geospatial processing tools, enabling performant, fully interactive map visualizations without internet access, external APIs, or built-in map services.

Map Json File

Snapshot of the custom GeoJSON file defining Egypt's governorate boundaries, spatial coordinates, and regions used to render the interactive Power BI map.
